# AGENTS.md

Agent instructions for this repository are maintained in README.md and CLAUDE.md.

Start with `hostname` (host rules in `CLAUDE.md`), then read in this order:

1. `README.md` — the compass: project orientation, hosts, open tasks, cognitive entry points
2. `CLAUDE.md` — operational rules and constraints; `autonomy.md` — the cycle delegation and its boundaries
3. specific node in `kb/` — for the area being worked on

The root exposes the six cycle collections `i1/`–`i3/` and `o1/`–`o3/`, each
with its own index, plus the local knowledge base `kb/`, the curated deck in
`presentation/`, generated views in `view/` (not versioned), and the `goal.md` and `world.md` registers. Read the dashboard
(`o1/plan.md` and the pertinent threads in `i3/`) each session; open the other
registers, catalogs, and collections when the work requires them. Every
collection item declares the `ciclo: dev|runtime` facet in its frontmatter.
