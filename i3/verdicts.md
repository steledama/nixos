# Verdicts

Indice della collezione `i3/`: lo **stadio i3** (Compare) del ciclo — il
verdetto attuale del progetto, un file per tensione aperta misurata contro un
obiettivo, non un log. Il git
log dice _cosa_ è cambiato; ogni filo dice _come stanno le cose ora_ e _perché
conta_. Specchio di `o1/plan.md` sul lato valutazione. Forma e disciplina
canoniche in [verdict](../method/verdict.md).

Ogni filo è lo **stato attuale**, aggiornato in place, non una sequenza di entry
datate (la cronologia di un filo è il git history del suo file). Quando un filo
si chiude — verdetto stabile, nessuna tensione aperta e nessuna altra funzione
viva — il file si rimuove: la storia resta in git. Il cursore di allineamento
resta, come previsto dal canone.

`goal.md` ([verdict](../method/verdict.md), «Che cosa è un filo»); l'indice non
